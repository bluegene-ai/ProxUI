常见问题
  • 连接被拒绝： 检查 Proxmox Web 界面是否可访问
  • SSL 错误： 使用自签名证书时请取消勾选“验证 SSL 证书”
  • 认证失败： 验证用户名/密码或令牌凭据
  • 网络超时： 确保防火墙放行 8006 端口
  • 使用 API 令牌时无数据： 创建令牌时请确保取消勾选“特权分离”，或为该令牌分配 PVEAuditor 角色
默认设置
  • Web 界面： https://your-ip:8006
  • 用户名： root@pam
  • 端口： 8006（HTTPS）
API 令牌设置
  • 前往 数据中心 → 权限 → API 令牌
  • 点击“添加”并选择一个用户（例如 root@pam）
  • 输入令牌 ID（例如“proxui”）
  • 取消勾选“特权分离” 以获得完整用户权限
  • 复制令牌密钥（仅显示一次！）
